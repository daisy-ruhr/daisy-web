# Datenschutz

## Diese Website verarbeitet keine personenbezogenen Daten

DAISY ist eine statische Website. Sie wird aus Markdown-Quellen gebaut und als reine
HTML-, CSS- und Bilddateien ausgeliefert. Es gibt:

* **kein Tracking** – keine Analytics, keine Cookies, keine Messung des
  Nutzungsverhaltens,
* **keine externen Ressourcen** – keine Webfonts, keine Skripte und keine Stylesheets von
  Drittanbietern; alle Dateien stammen von unserer eigenen Domain,
* **keine Server-Log-Auswertung** für Analyse- oder Werbezwecke,
* **keine personenbezogenen Formulare** – Kontakt erfolgt über eine
  E-Mail-Adresse, die Sie selbst in Ihrem Mailprogramm verwenden.

Sie können das selbst prüfen: Beim Laden dieser Seite werden ausschließlich Dateien von
ihrer Domain geladen.

## Hosting

Die Website wird über GitHub Pages ausgeliefert. Dabei verarbeitet der Hoster
(GitHub Inc. , USA) aus technischen Gründen Zugriffsdaten in Server-Logfiles
(IP-Adresse, Zeitpunkt, angeforderte Datei, Browsertyp). Rechtsgrundlage ist Art. 6 Abs. 1
S. 1 lit. f DSGVO – berechtigtes Interesse am sicheren Betrieb. Details regelt die
Datenschutzerklärung von GitHub.

## Ihre Rechte

Sie haben das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung,
Datenübertragbarkeit und Widerspruch sowie das Recht, sich bei einer Aufsichtsbehörde zu
beschweren. Da diese Website keine personenbezogenen Daten verarbeitet, richtet sich ein
entsprechendes Anliegen an den oben genannten Hoster.
