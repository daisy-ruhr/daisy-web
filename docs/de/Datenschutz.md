# Datenschutz

## Wir erheben selbst keine personenbezogenen Daten

DAISY ist eine statische Website. Sie wird aus [Markdown-Quellen](https://github.com/daisy-ruhr/daisy-web/) gebaut und als reine
HTML-, CSS- und Bilddateien ausgeliefert. Es gibt:

* **kein Tracking** – keine Analytics, keine Cookies, keine Messung des
  Nutzungsverhaltens,
* **keine externen Ressourcen** – keine Webfonts, keine Skripte und keine Stylesheets von
  Drittanbietern; alle Dateien stammen von unserer eigenen Domain,
* **keine Server-Log-Auswertung** für Analyse- oder Werbezwecke,
* **keine personenbezogenen Formulare** – Kontakt erfolgt über eine
  E-Mail-Adresse, die Sie selbst in Ihrem Mailprogramm verwenden.

Sie können das selbst prüfen: Beim Laden dieser Seite werden ausschließlich Dateien von
ihrer Domain geladen.

## Hosting

Die Website wird bei statichost.eu gehostet (Variable Object Assignment, c/o Knackeriet,
Sankt Paulsgatan 25, 118 48 Stockholm, Schweden). Zur Auslieferung setzt statichost.eu
Server der Hetzner Online GmbH (Deutschland) und das Content-Delivery-Netzwerk von
BunnyWay d.o.o. (Slowenien) ein.

Beim Aufruf der Website wird Ihre IP-Adresse aus technischen Gründen verarbeitet, um die
angeforderten Dateien an Ihr Gerät auszuliefern. Nach Angaben des Hosters werden dabei
keine personenbezogenen Daten in Logfiles gespeichert; protokolliert werden nur technische
Angaben wie Zeitpunkt, angeforderte Adresse und Datenmenge, die höchstens 7 Tage
aufbewahrt werden. Rechtsgrundlage ist Art. 6 Abs. 1 S. 1 lit. f DSGVO – berechtigtes
Interesse an einer sicheren und zuverlässigen Bereitstellung der Website. Der Hoster
verarbeitet diese Daten in unserem Auftrag (Art. 28 DSGVO); eine Übermittlung in Länder
außerhalb der EU bzw. des EWR findet nicht statt. Details regelt die
[Datenschutzerklärung von statichost.eu](https://www.statichost.eu/privacy/).

Der Quelltext der Website liegt auf GitHub (GitHub Inc., USA). Beim Besuch der Website
werden jedoch keine Daten an GitHub übertragen; nur wenn Sie den Link zum Quelltext
anklicken, gilt die Datenschutzerklärung von GitHub.
