# Notes about logo usage

Notice: Logo files are only part of this repository to represent the organization. For legal use of these logos, please contact the respective organization and reference their specific Corporate Design guidelines.

(no guarantee for legal correctness of below info)

## RUB

Minimum logo height: 36px
Protected area: 1/5 of logo (cube) height

Check whether department-specific logo is to be used

## BoWE

Only a low-quality JPEG is officially provided at https://www.bochum.de/Referat-fuer-politische-Gremien-Buergerbeteiligung-und-Kommunikation/Bochum-Wirtschaftsentwicklung

Used high-quality vector from website source

Protected area is complex (about the book/arrow height vertically and its width horizontally to be safe)

## UW/H

Min. logo h.: 8mm, better 14mm
Protected area: 1/4 of logo height, better 1/2

Official logo download is not publically accessible, used high-quality vector website logo

Check whether logo with claim must be used

## UDE

Official logo download is not publically accessible, used high-quality vector website logo

Logo with claim must be used
No official guidance on min. logo size or protected area
