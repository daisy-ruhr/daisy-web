We do not collect any personal data ourselves¶

DAISY is a static website. It is built from Markdown sources and delivered as plain HTML, CSS and image files. There is:

  • no tracking – no analytics, no cookies, no measurement of usage behavior,
  • no external resources – no web fonts, no scripts and no stylesheets from third parties; all files come from our own domain,
  • no server log analysis for analytics or advertising purposes,
  • no forms collecting personal data – contact is made via an e-mail address that you use yourself in your mail program.

You can verify this yourself: when loading this page, only files from its own domain daisy.ruhr are loaded.

Hosting¶

The website is hosted by statichost.eu (Variable Object Assignment, c/o Knackeriet, Sankt Paulsgatan 25, 118 48 Stockholm, Sweden). For delivery, statichost.eu uses servers of Hetzner Online GmbH (Germany) and the content delivery network of BunnyWay d.o.o. (Slovenia).

When you visit the website, your IP address is processed for technical reasons in order to deliver the requested files to your device. According to the host, no personal data is stored in log files; only technical details such as time, requested address and data volume are logged and kept for at most 7 days. The legal basis is Art. 6(1)(f) GDPR – legitimate interest in providing the website securely and reliably. The host processes this data on our behalf (Art. 28 GDPR); no transfer to countries outside the EU/EEA takes place. Details are governed by the statichost.eu privacy policy.

The source code of the website is stored on GitHub (GitHub Inc., USA). Visiting the website does not transfer any data to GitHub; GitHub's privacy policy only applies if you follow the link to the source code.
